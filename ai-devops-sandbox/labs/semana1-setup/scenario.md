# Semana 1 — Preparación del entorno

Esta semana no hay un bug ni un problema técnico que resolver — es de conceptos
(ver currícula: "DevOps moderno e introducción a la IA" + "Fundamentos de IA para ingenieros").

## Tu tarea

1. Crea tu copia de este repo usando **"Use this template"**.
2. Ábrelo en GitHub Codespaces (o levántalo local si prefieres — ver `.devcontainer/devcontainer.json`).
3. Confirma que la app de ejemplo corre:
   ```bash
   cd app/api
   pip install -r requirements.txt
   python app.py
   ```
   Deberías poder visitar `http://localhost:8080/health` y ver `{"status": "ok"}`.
4. Copia `bitacora/template.md` a `bitacora/mi-bitacora.md`.
5. Llena el **Diagnóstico inicial** de la Semana 1 en tu bitácora — sé honesto sobre tu
   nivel de experiencia con IA hoy, ya que es tu punto de comparación al final del curso.
6. Decide y anota tu **Ruta**: A (este sandbox) o B (problema propio de tu trabajo).

## Qué documentar en tu bitácora esta semana

El diagnóstico inicial completo (ya está en el template) — nivel de experiencia, herramienta
que usas, y una descripción de tu entorno de trabajo real.
